# Imperfekt - toolkit for dot matrix printers

This is Imperfekt. Go Toolkit for Dot matrix printers.

Should you have one somewhere in the attic, use it to give it a new life. It's so much fun!

I bought myself Dot Matrix Printer, only to later discover, that there is not much software
to actually support those fantastic devices.

## (non-)Goals

- Preserve the Dot Matrix Printing Technology from dying completely
- Allow the others of creating Dot Matrix Printer Software
- Maybe allow the community to revive / extend / rewrite - useful pieces of software
- Print envelopes
- Print my master’s thesis lol
- Sheer fun, tinkering.
- _Brrt! Brrt! Brrt! Shhhhhhh! Beep beep beep!_

## The name 

Root of the name came out of my convoluted imagination:

- WordPerfect - was a great word processing system that utilized many Dot Matrix Printers
- Imperfekt - German past tense referencing continuing or repeated event or state (dot matrix printer actually is complex state machine)
